# Shaik Attar Sana Portfolio

## Goal
Build a polished, responsive one-page portfolio that presents Sana as a backend and GenAI specialist, with fast access to work history, projects, skills, résumé, and contact details.

## Experience
- Create a dark technical visual system with emerald, cyan, and indigo accents, crisp typography, subtle grid texture, restrained glow, and motion that respects reduced-motion preferences.
- Add a compact sticky navigation and a strong first screen with animated role text, location, profile summary, social/contact shortcuts, and résumé/contact actions.
- Organize skills into four scannable groups with concise badges and clear visual hierarchy.
- Present employment and education as an interactive timeline with readable achievements.
- Build a filterable project grid for All, AI/ML, and Backend/Full Stack, with rich cards and accessible detail dialogs.
- Add a contact area with direct email, LinkedIn, tap-to-call, copy email/phone feedback, and a form that opens a prepared email in the visitor’s mail app.
- Add a résumé dialog designed for both on-screen reading and browser printing/saving as PDF.

## Technical details
- Keep the experience on the existing home route and add complete route-specific social and search metadata.
- Use React state for filters, dialogs, copy feedback, navigation, and typing animation; no account or stored data is needed.
- Use semantic design tokens in the shared stylesheet and Lucide icons for interface controls.
- Ensure keyboard-accessible dialogs, visible focus states, sensible headings, descriptive labels, and mobile-safe layouts.
- Validate the result in the running preview at desktop and mobile widths, then check the latest build and runtime diagnostics.
